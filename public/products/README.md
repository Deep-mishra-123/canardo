| Filename | Fragrance |
| --- | --- |
| `IMG-20261106-WA0069.jpg` | Vetiver |
| `IMG-20261106-WA0070.jpg` | Sandalwood |
| `IMG-20261106-WA0071.jpg` | Lavender |

| `IMG-20261106-WA0073.jpg` | Jasmine |
| `IMG-20261106-WA0074.jpg` | Bergamot |

Do not rename the files. The data layer already maps these paths to the correct fragrance.

`hand-liquid-wash.svg` is a temporary branded concept placeholder, not a product photograph. Replace it via the admin dashboard when the official Hand Liquid Wash image is available.

Run:

```bash
npm run check:assets
```
